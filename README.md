# Corerope

An open research program on making a frontier-quality LLM roughly **1000x cheaper to run**, in
energy and dollars per solved task. The site is [corerope.space](https://corerope.space).

It has two layers:

1. **The survey** ([research/01-report-path-to-1000x.md](research/01-report-path-to-1000x.md) and the
   six notes in [research/notes/](research/notes/)) maps every known efficiency lever as of November
   2026. Against a 2024 baseline, 1000x is mostly the market trend. Against the late-2026 frontier,
   the known levers give about 35x in dollars and 80x in energy, because most of them shrink the same
   bytes moved per token.
2. **The design** ([research/02-corerope-design.md](research/02-corerope-design.md)) invents the stack
   needed to close that gap: a small ternary reasoning core wired into silicon, a large lookup memory
   in storage, a core frozen for years, a via-programmed fabric, tokens priced per task, context
   cartridges and a two-tier fleet. Its cost model's central case is about 749x less energy and 263x
   lower cost per solved task, with a range of 15x to 46,009x.

## Status

**A design, not a result.** Nothing in it is proven at scale. The experiments so far test only the
silicon arithmetic (gate counts for wired layers, an add-count model of shared partial sums) and the
cost model behind the charts. Every model-quality claim is untested. The seven experiments that would
confirm or kill the design are in the design doc and on
[corerope.space/experiments](https://corerope.space/experiments).

Known gaps in the evidence:

- No published measurement of how the efficiency levers compound together at frontier scale.
- Gate counts exclude wire energy and used Yosys without ABC optimization.
- All model-quality claims of the design are untested.
- Several 2026 figures are vendor claims or secondary sources; the notes mark them.

## Layout

```
00-BRIEF.md        the brief the site was built from
research/          the survey, the design doc and six notes: the source of truth for every page
experiments/       wired-layers (Yosys gate counts), spw-model (adds.py), cost-model (costmodel.py),
                   and RESULTS.md, the recorded outputs
scripts/           synth.sh (re-runs the syntheses), check_results.py, data/*.py (writes data/)
data/              JSON for the charts, generated by `make data`, never edited by hand
site/              the website (Next.js), reading research/, experiments/ and data/ at build time
tools/             lint, screenshot, browser and deploy tools for the site
```

## Reproduce

You need Python 3.12, Node 24 and pnpm 10. `uv` is used when present.

```sh
make venv     # .venv with numpy and yowasp-yosys (experiments/requirements.txt)
make synth    # re-run the 15 wired-layer syntheses with Yosys 0.71 (minutes)
make data     # write data/*.json from the research and the experiment scripts
make check    # compare every recorded result in experiments/RESULTS.md, and test the
              # site's TypeScript cost model against costmodel.py bit for bit
```

`make check` re-runs costmodel.py and requires its output to equal RESULTS.md character for
character, then checks the SPW ratios (from adds.py, via `make data`) and, after `make synth`, all 15
gate counts. A part that was not re-run is reported as skipped, never as passed. Each chart on the site
names the data file and the script that produced it.

## The site

```sh
pnpm install
pnpm dev                  # http://localhost:3000
pnpm build                # every page is static
pnpm lint                 # Biome, plus a check that no file has an em dash
pnpm typecheck && pnpm test
```

Each page links to the lines of the research file it renders, and each chart to its data and script.
The cost-model calculator is a TypeScript port of `experiments/cost-model/costmodel.py`; its test
compares every output field with the Python's for every preset and sweep (`data/costmodel-golden.json`).

Deploys go through `tools/site/deploy.sh`, which uploads the committed tree to Vercel and proves the
live site serves that commit.
